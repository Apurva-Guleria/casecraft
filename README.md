
# CaseCraft 🕵️

An AI-powered mystery investigation game where players analyze clues, connect evidence, investigate suspects, and solve fictional cases.

## Project Status

🚧 In Development

## Planned Features

- Interactive mystery cases
- Suspects and evidence investigation
- Evidence connections and timelines
- AI-powered hints and explanations
- Case scoring and progress tracking

## Tech Stack

- Python
- FastAPI
- React
- TypeScript
- PostgreSQL
- Large Language Model (LLM) integration
